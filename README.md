# 动漫杀 · 战术演示版

零依赖、可直接在浏览器运行的单机卡牌游戏 Demo。目前包含经典军八、排位2V2、20名角色与项目内立绘、37种原创二次元风格卡牌插画、按漫画作品分类的选人界面、可点击的角色主动技，以及由6种基础牌、19种策略牌、12种装备牌组成的完整牌库。军八使用144张标准牌堆，2V2使用80张精简牌堆。

策略牌同时包含暗置伏笔、能量交易、装备转移、行动时序和5种直接伤害策略。群体策略按座次逐人响应，单个目标的反制不会取消其他人的结算。每名角色的伏笔区最多同时保留2张不同名伏笔，不限制每回合布置次数；敌方只能看到设置者、数量与指定目标，不能查看牌名、效果或持续时间。对战中可通过角色详情查看实时状态与技能，也可用手牌放大按钮阅读完整卡牌规则。

角色的体力与手牌上限为两个独立属性：初始手牌等于角色手牌上限，受伤不会降低手牌上限；界主两项上限及初始手牌额外+1，记忆晶体继续提供手牌上限+2。

首个角色扩展包为《火影忍者·忍界初阵》，现包含漩涡鸣人、我爱罗、春野樱、奈良鹿丸、宇智波鼬、宇智波佐助、旗木卡卡西、日向雏田、自来也和大蛇丸共10名角色。角色技能会与基础牌类别、伏笔区、装备转移、弃牌堆复刻、隐藏情报和行动队列直接联动。樱可以在主动技中选择蓄印或解放百豪牌；鼬的任意虚假伏笔都可用于乌鸦替身，月读还能造成伤害；鹿丸的战术预读与雏田的六十四掌也提供控制后的进攻收益。影分身、百豪牌与月读封存牌进入独立特殊牌区，不计入手牌上限；自来也则以蛤蟆口束缚、仙术印和仙法·五右卫门完成攻守联动。

## 运行

需要 Node.js 18 或更新版本：

```powershell
npm start
```

然后打开 `http://localhost:4173`。

## 测试

```powershell
npm test
```

## Windows 与 Android 应用

应用封装层位于 `packaging/`，Windows 与 Android 共用同一份离线 `www/` 资源，并支持在大厅继续未完成的本地对局。

```powershell
npm run app:install
npm run app:test
npm run desktop:dist
```

Windows 构建会生成 x64 安装版和便携版。Android 工程可用 `npm run android:prepare` 生成，最低支持 Android 7/API 24并锁定横屏。完整依赖、产物位置和签名说明见 [PACKAGING.md](./PACKAGING.md)。

推送 `v0.1.1` 标签后，GitHub Actions 会自动构建 EXE 与测试 APK，并发布到公开 GitHub Release。演示版没有商业代码签名，Windows 可能显示 SmartScreen 提示；Android 测试 APK 不能直接提交应用商店。

本项目是个人非商业玩法原型。角色名称仅用于内部玩法验证；任何公开发布版本均需取得相应授权或替换为原创角色与素材。
