# 动漫杀 Demo 0.2.1

移动端适配修复版，包含 Windows x64 安装版、Windows x64 便携版和 Android 7+ 横屏测试 APK。

- 全部内容支持离线运行。
- 大厅可继续未完成对局；对局保存覆盖回合、响应、弃牌和战术选择。
- 修复安卓横屏高度较小时牌桌下半区、玩家手牌与操作区被裁切的问题。
- 增加 1368×573 与 915×412 紧凑布局，并将行动面板改为右侧抽屉。
- 支持刘海安全区，系统状态栏与导航栏统一为深色。
- Windows 版本未购买商业代码签名证书，首次运行时可能出现 SmartScreen 提示。
- Android APK 使用测试签名，仅用于侧载体验，不能直接提交应用商店。

本项目是个人非商业玩法原型。公开或商业发行前，需要取得角色、名称、立绘及其他相关素材的授权，或替换为原创内容。
