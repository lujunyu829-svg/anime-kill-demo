# v0.2.0 第二轮角色数值复测记录

本轮在修正忍界初阵与伟大航路核心机制后，使用 `npm run balance:test -- --games=100` 对排位 2V2 进行四个先手座位复测。每个角色 400 局，固定种子，记录角色位于苍队时的胜率；该数据用于发现极端值，不替代真人局结论。

## 本轮已落实的校准

- 我爱罗：体力上限 4→3；砂瀑大葬未弃牌时伤害 2→1；绝对防御仅作用于普通突击。
- 自来也：蛤蟆口束缚消耗 1→2，每轮一次保持不变。
- 春野樱：百豪区上限 2→3，招牌技消耗 4→3；手牌上限 5。
- 旗木卡卡西：招牌技消耗 3→2；手牌上限 5。
- 大蛇丸：体力上限 3→4，招牌技消耗 3→2。
- 乌索普：招牌技消耗 4→3。
- 罗宾：百花搜查取消能量消耗，巨大树消耗 4→3。
- 布鲁克：灵魂乐章改为每轮一次并消耗 1 点能量；手牌上限回到 4。
- 路飞：见闻色检出的非基础牌置于牌堆底；甚平 AI 优先保护公开队友。
