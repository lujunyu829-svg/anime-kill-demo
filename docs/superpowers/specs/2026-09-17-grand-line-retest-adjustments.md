# 《动漫杀》伟大航路复测后调整需求文档

日期：2026-09-17  
适用版本：0.2.0后续平衡修订  
文档性质：机制修正、角色调整、基础系统调整与复测验收需求  
实施范围：只调整“伟大航路”角色及与其直接相关的公共结算，不增加角色，不调整基础牌堆

## 1. 本轮目标

第一轮调整已经消除了布鲁克、路飞、甚平等角色的大部分极端胜率，并完成护盾封顶、2V2首行动座位随机化和部分隐藏身份AI隔离。当前版本的主要问题已从“大量角色严重失衡”转为以下三类：

1. 部分角色胜率已经正常，但技能或觉醒仍未按文案完整生效。
2. 乌索普和弗兰奇在特定环境下仍处于强度下限附近。
3. 弗兰奇与乔巴形成1V1时可能进入数百轮资源循环。

本轮调整必须遵守“先修机制、再做数值”的顺序。不能因为当前AI胜率处于50%左右，就保留与文案不一致的结算；也不能在核心技能尚未生效时直接增加体力、手牌或伤害。

## 2. 复测结论摘要

- 路飞、索隆、娜美、山治、乔巴、布鲁克和甚平的当前胜率已进入40%至60%观察区间。
- 罗宾纯包胜率42.27%、混合池47.17%，已经脱离明显弱势区，但仍需要补完觉醒效果。
- 乌索普纯包胜率38.37%、混合池43.67%，仍然偏弱；其谎言回收、诈术收益和狙击距离尚未完整生效。
- 弗兰奇纯包胜率39.24%、混合池47.19%，不能简单判定为弱势。他在混合池表现正常，却是极端长局的核心参与者。
- 布鲁克由76.7%降至55.85%，未觉醒免死与灵魂乐章问题的第一轮修正有效。
- 甚平由30.5%升至50.90%，侠义与护航方向的第一轮修正有效。
- 梦想航迹仍不均衡：乔巴4.05%、山治7.50%、索隆11.65%、乌索普15.25%过低，弗兰奇73.90%略高。
- 2V2苍、绯队总体胜率已达到49.50%和50.50%，随机首行动座位解决了固定阵营不公平。
- 先行动一方本身仍有约59%的胜率优势，需要通过首回合规则继续收敛。
- 护盾已稳定封顶3点，但10000局2V2仍有30局超过80轮，6局达到4000步上限；全部超长局包含弗兰奇，其中26局同时包含乔巴。
- 当前74项自动化测试全部通过，但现有测试没有覆盖多项仍与文案不一致的角色行为。

## 3. 测试口径与样本

### 3.1 主要样本

1. 纯伟大航路2V2：每名角色在四种首行动座位下各500局，共20000局。
2. 混合28人角色池2V2：每名伟大航路角色在四种首行动座位下各300局，共12000局。
3. 纯伟大航路终局压力测试：10000局2V2，每局最多4000步。
4. 纯伟大航路军八压力测试：4000局，每局最多8000步。
5. 项目快速平衡门禁：20名扩展包角色各400局，共8000局，用于确认没有大范围回归；该样本不计入主数据表。
6. 十名角色最小状态探针：直接验证技能状态、觉醒收益、穿甲、封存、净化和谎言去向。

主报告共使用46000局模拟。所有批量模拟均使用可复现伪随机种子。

### 3.2 “四座位归一化”的准确含义

当前平衡脚本固定被测角色为0号玩家，分别让0、1、2、3号座位成为本局首行动者。因此本报告中的归一化结果准确含义是“四种首行动座位归一化”，不是把被测角色分别放入四个玩家座位。

后续脚本输出应把`seat0`至`seat3`改名为`anchor0`至`anchor3`，避免误读。若需要真正测试角色座位影响，应另行增加角色换座样本。

### 3.3 结论限制

- AI会低估需要保牌、等待治疗时机、选择装备价值或主动放弃技能的角色。
- 纯包数据反映同扩展包内部克制，混合池数据更接近实际选将环境，两者必须同时查看。
- 觉醒角色的平均觉醒轮次只统计成功觉醒的对局，不能代替觉醒率。
- 当前仍有技能实现缺口，修复后必须按相同种子和样本量重新测试。

## 5. 基础机制调整

### M-01 修正卡牌事件生命周期

当前通用出牌流程仍在牌离开手牌后、实际效果和反制完成前发送`cardResolved`。这会让娜美气象棒、梦想类别统计以及未来依赖结算结果的技能过早触发。

调整要求：

- 牌合法声明并支付后发送`cardDeclared`。
- 被谎言、反制、咒印、节奏断点等取消时发送`cardCancelled`。
- 基础效果、目标选择、反制和多目标序列全部完成后才发送`cardResolved`。
- 同一实体牌只能在`cardCancelled`和`cardResolved`中出现一个终态事件。
- `cardResolved`携带`sourceId`、`targetIds`、`card`和实际变化摘要。

优先级：P0。未修复前，娜美和乌索普的航迹数据不能作为最终平衡依据。

### M-02 统一攻击修正

当前一次性穿甲标记已经能够进入通用攻击流程，但山治黑足、甚平鱼人空手道和索隆阿修罗等持续条件仍未统一接入。

调整要求：

- 攻击声明统一计算`damage`、`requiredGuards`、`range`、`ignoreArmor`、`skipIntervene`和`onComplete`。
- 一次性强化只在合法攻击声明后消耗；目标无效或出牌被取消时保留。
- 普通突击与攻击型招牌技共用修正入口，但角色规则可以明确限制只作用于普通突击。
- 禁止继续在防具结算阶段通过散落的角色ID判断穿甲。

优先级：P0。

### M-03 调整梦想航迹体验区间

统一工程目标：

- 觉醒率：25%至70%。
- 成功觉醒对局的平均觉醒轮次：3至7轮。
- 每轮最多推进1点，到3点立即觉醒。
- 被取消的牌、没有实际回复、没有增加护盾和没有清除异常的效果不推进。

索隆、乌索普、山治和乔巴低于下限；弗兰奇略高于上限。梦想条件调整必须优先于基础体力、手牌和伤害调整。

优先级：P0。

### M-04 降低首行动方优势

随机首行动座位已使苍、绯队总体胜率达到49.50%和50.50%，但首行动方在四种座位下的胜率均约为59%。

调整要求：排位2V2第一轮的首行动玩家只摸1张牌，后续回合恢复摸2张。能量获取、出牌次数和其他规则暂不调整。复测首行动阵营胜率；若仍高于55%，再考虑首行动玩家第一回合不能从首次造成伤害获得能量。

优先级：P1。该规则会影响所有角色，必须单独提交和单独复测，不与角色数值改动混在同一批样本中。

### M-05 启用长局收束规则

10000局纯包2V2中：

- 苍队4947胜、绯队5047胜、6局未完成。
- 平均7.54轮，P95为16轮，P99为35轮，最大510轮。
- 30局超过80轮，全部包含弗兰奇，26局同时包含乔巴。
- 6局未完成全部进入弗兰奇与乔巴的1V1。
- 护盾始终没有超过3，说明当前根因不再是护盾无限增长，而是换装、防御、治疗和护盾的重复资源循环。

调整要求：

1. 先修正弗兰奇和乔巴AI，1V1时优先造成伤害，不反复进行等价值换装或无收益资源操作。
2. 增加发布级长局保险：第40轮起进入“裂隙收束”。每名角色在自己回合结束时失去1点体力，该体力损失绕过护盾和防具、不能被减伤，但允许正常重伤救援。
3. 裂隙收束必须显示状态提示并写入存档，恢复后轮数和触发顺序保持确定。
4. 该规则只处理极端局，不改变前39轮的正常平衡。

优先级：P0处理AI循环，P1加入全局收束保险。

### M-06 补充平衡报告字段

`scripts/balance-simulation.mjs`后续至少输出：

- 角色、首行动座位、阵营和胜者。
- 纯包胜率、混合池胜率和四种首行动座位胜率。
- 航迹进度、觉醒率、觉醒轮次和觉醒原因。
- 主动技次数、招牌技次数、伤害、治疗和护盾获取。
- 平均轮数、P95、P99、最大轮数和未完成数。
- 超过80轮的阵容组合。

输出字段使用`anchor0`至`anchor3`，不再使用容易误解的`seat0`至`seat3`。

优先级：P1。

## 6. 十名角色调整要求

### 6.1 蒙奇·D·路飞

当前数据：纯包56.85%，混合池57.71%，觉醒率63.10%。

当前问题：

- 见闻色遇到非基础牌时，实际效果已经改为置于牌堆底，但角色数据仍写“收入手牌”。
- 见闻色展示基础牌时只把该牌弃置，没有实际减少本次所需防御数。
- 越战越勇尚未产生下一次突击加伤。
- 如果完全按旧文本补齐越战越勇，二档每次主动失去体力都能稳定换取额外伤害，可能使路飞重新超过60%。

调整要求：

1. 正式采用当前削弱方向：见闻色展示非基础牌时置于牌堆底，不再收入手牌，并同步角色文字。
2. 展示基础牌时将其弃置，并令本次攻击所需防御数减少1，最低为0；这才算“视为1张防御”。
3. 越战越勇改为“每轮首次因其他角色造成的伤害失去体力后，下一次普通突击伤害+1”。二档的主动失去体力不触发。
4. 强化可跨回合保留，只在合法普通突击声明时消耗。
5. 二档、五档、体力和手牌上限暂不改动。

复测门槛：纯包或混合池高于60%时，优先把二档摸牌由2降为1；低于45%时再恢复越战越勇对二档失血的触发。

### 6.2 罗罗诺亚·索隆

当前数据：纯包57.53%，混合池56.01%，觉醒率11.65%。

当前问题：

- 三刀流强化突击没有推进梦想。
- 阿修罗仍未稳定通过统一攻击规则忽略防具。
- 剑士本能的摸牌当前按每轮一次实现，角色文字仍写每回合首次。
- 直接把所有三刀流结算都计入航迹，可能让觉醒率从11.65%跃升到过高区间。

调整要求：

1. 梦想条件明确为“每轮首次以三刀流强化突击造成伤害，或以阿修罗造成伤害时推进”。必须命中，不以单纯声明或被完全防御推进。
2. 阿修罗始终忽略防具、允许正常强制介入；未觉醒消耗4，觉醒后消耗3且命中摸1。
3. 剑士本能统一为“每轮首次普通突击被完全防御后摸1张”，同步角色文字。
4. 武器距离额外+1、三刀流伤害和防御需求保持不变。

复测门槛：目标觉醒率25%至55%；胜率高于60%时先取消觉醒阿修罗的命中摸牌，不调整体力。

### 6.3 娜美

当前数据：纯包53.93%，混合池57.83%，觉醒率37.75%。

当前问题：

- 觉醒航海术在前四张不存在两种类别时，仍会取得两张同类别牌。
- 顺风航线被反制返还手牌尚未形成完整终态结算。
- 雷云宙斯在目标拥有两张手牌时强制弃牌，没有提供“弃牌或受伤”的选择。
- 过早发送`cardResolved`会提前触发气象棒和梦想类别统计。

调整要求：

1. 觉醒航海术第一张任意选择，第二张只显示不同类别候选；没有候选时只获得第一张。
2. 顺风航线在下一张单目标策略声明时提供无视距离；该牌被反制时实体牌返回娜美手牌，结算或取消后清除顺风状态。
3. 雷云宙斯由目标选择弃2张牌或受到2点策略伤害；手牌不足2张时只能选择伤害。
4. 气象棒和梦想只监听真正的`cardResolved`。
5. 体力、手牌、航海术看牌数和招牌技消耗暂不改动。

复测门槛：混合池高于60%时，将气象棒由每回合首次改为每轮首次；低于45%时不执行该限制。

### 6.4 乌索普

当前数据：纯包38.37%，混合池43.67%，觉醒率15.25%。

当前问题：

- 谎言目前只拦截普通突击和策略牌，没有覆盖装备牌及其他非响应基础牌。
- 目标弃牌继续后，乌索普没有因诈术回收摸1。
- 当前牌被取消后，乌索普没有获得1能量。
- 觉醒后每轮首次触发的谎言仍进入弃牌堆，没有返回手牌。
- 狙击王对谎言目标的无视距离尚未统一接入卡牌目标计算。

调整要求：

1. 谎言拦截目标下一张任意非响应牌，包括基础牌、策略牌和装备牌。
2. 目标可弃置当前牌之外的1张手牌继续；没有可弃牌时当前牌自动取消。
3. 弃牌继续：移除谎言，乌索普摸1张；取消当前牌：移除谎言，乌索普获得1能量。
4. 每轮首次因乌索普效果令目标弃牌或取消牌时推进梦想。
5. 觉醒后每轮首次触发的谎言暗置牌返回乌索普手牌；本轮后续谎言正常进入弃牌堆。
6. 狙击王令乌索普对谎言目标使用普通突击和单目标策略无视距离。
7. 狼草消耗保持3能量；有谎言时消耗谎言、忽略防具且不可介入。

复测门槛：先完整实现机制，不增加体力或手牌。完整机制后纯包仍低于40%时，再把谎言弹能量消耗由1降为0。

### 6.5 文斯莫克·山治

当前数据：纯包49.90%，混合池53.42%，觉醒率7.50%。

当前问题：

- 黑足只有距离+1生效，未装备武器时的忽略防具没有生效。
- 治疗他人后没有生成援护反击状态。
- 梦想只从实际治疗推进，交出牌没有统一事件，导致觉醒率过低。

调整要求：

1. 未装备武器时，普通突击距离+1并忽略防具。
2. 每轮首次令他人实际回复或获得自己交出的牌后，获得一次援护反击。
3. 援护反击持续到下一次普通突击或魔神风脚：普通突击无视距离且额外需要1张防御；魔神风脚不可介入。声明后清除。
4. 增加`cardTransferred`事件，战术接力、献策、记忆交换等实际把山治的牌交给他人时均可推进梦想。
5. 梦想推进与援护反击共用每轮首次援助判定，避免一次援助重复计算。
6. 海上餐厅及觉醒摸牌效果保持不变。

复测门槛：先补全机制。若胜率高于60%，将援护反击限制为只强化普通突击，不再使魔神风脚不可介入；若觉醒率仍低于25%，成功发动海上餐厅即推进，不再要求产生实际回复。

### 6.6 托尼托尼·乔巴

当前数据：纯包50.20%，混合池53.17%，觉醒率4.05%。

当前问题：

- 诊断已能在治疗他人后让双方摸牌。
- 毛皮强化仍未进入防御资源选择。
- 觉醒医术一次清除了全部毒、少摸牌、能量封锁和招牌技封锁，而不是只清除一项。
- AI只会稳定为自己使用恢复，对受伤队友使用医术的优先级不足。
- 弗兰奇与乔巴1V1会形成极端资源循环。

调整要求：

1. 每轮首次需要防御时，乔巴可将1张非响应基础牌当作1张防御；允许放弃发动。
2. 觉醒医术只选择清除一项：1层毒、1次少摸牌、能量封锁或1层招牌技封锁。
3. 满体力但有异常的目标可以接受觉醒医术；成功清除异常也视为梦想推进条件。
4. 梦想条件调整为“每轮首次令他人实际回复，或以医术清除他人至少一项异常”。
5. AI在队友体力不高于2、存在两层毒或被能量封锁时优先使用医术，不要只按主动技随机概率判断。
6. 1V1进入40轮后停止为满护盾状态重复发动怪物强化；优先保留突击和伤害策略。

复测门槛：目标觉醒率25%至55%。胜率高于60%时，怪物强化护盾由2降为1；在此之前不调整数值。

### 6.7 妮可·罗宾

当前数据：纯包42.27%，混合池47.17%，觉醒率27.20%。

当前问题：

- 觉醒百花搜查仍只查看1张牌。
- 没有非响应手牌的目标仍可能成为合法目标，导致主动技空耗。
- 历史学者缺少独立的每轮首次摸牌标记；觉醒查看两张后可能重复触发。
- 巨大树在军八仍可能使用真实阵营筛选目标。

调整要求：

1. 百花搜查只允许选择至少拥有1张非响应手牌的目标。
2. 未觉醒随机展示1张；觉醒后随机展示最多2张，由罗宾选择其中1张作为封存候选。
3. 历史学者每轮首次查看隐藏牌后摸1张，查看多张仍只触发一次。
4. 封存牌继续在原持有者下回合开始归还，保持当前`returnAtPlayerId`方向。
5. 巨大树在2V2作用于敌队；军八作用于所有其他存活角色，不读取隐藏真实阵营。
6. 百花搜查0能量、巨大树3能量保持不变。

复测门槛：补完觉醒后若纯包仍低于40%，百花搜查成功封存时令罗宾获得1能量；当前不提前增加收益。

### 6.8 弗兰奇

当前数据：纯包39.24%，混合池47.19%，觉醒率73.90%，平均10.54轮。

当前问题：

- 纯包略低但混合池正常，不能用单一胜率直接补强。
- 梦想略快，主动技和招牌技使用频率远高于其他角色。
- 所有超过80轮的压力样本都包含弗兰奇。
- 装备变化事件仍需严格区分装备所有者`ownerId`与变化来源`sourceId`。
- AI会进行等价值换装，并在1V1中持续回收防具和恢复资源。

调整要求：

1. 可乐能源和梦想以`ownerId === franky.id`的实际装备进入或离开为判断，不以事件来源角色判断。
2. 同一次装备替换只触发一次可乐能源检查和一次梦想检查。
3. 觉醒工坊替换下来的旧装备继续返回手牌，保持现有方向。
4. AI只在新装备价值更高、补充空槽、触发关键能源或解决致命威胁时直接替换。
5. 1V1中若自己已有武器和防具，降低改造工坊与弗兰奇将军优先级，提高突击和伤害策略优先级。
6. 梦想条件第一轮不改；修正事件重复和AI后重新统计。觉醒率仍高于70%时，改为“每轮首次由自己的主动技或招牌技令装备进入自己的装备区”才推进。
7. 不增加体力、护盾、招牌技伤害或工坊收益。

复测门槛：纯包允许处于40%附近，但混合池必须保持40%至60%；弗兰奇参与的对局P99不超过35轮，弗兰奇对乔巴1000局专项测试不得超过80轮。

### 6.9 布鲁克

当前数据：纯包55.85%，混合池55.17%，觉醒率50.45%。

当前问题：

- 未觉醒免死已经修复。
- 灵魂乐章的频率和能量成本调整有效。
- 黄泉寒气仍可在同一回合多次施加少摸牌，没有遵守“每回合首次”。

调整要求：

1. 黄泉寒气增加本回合标记，只有第一次普通突击造成伤害时施加少摸牌。
2. 灵魂乐章保持每轮一次、消耗1能量，不恢复额外少摸牌。
3. 觉醒免死保持每局一次、仅伤害触发；失去体力不触发。
4. 箭尾斩完全防御后仍施加少摸牌，保持不变。
5. 不调整体力、手牌和招牌技消耗。

复测门槛：修正黄泉寒气后胜率预计轻微下降；只有低于42%时才考虑取消灵魂乐章的1能量消耗。

### 6.10 甚平

当前数据：纯包50.90%，混合池53.08%，觉醒率57.05%。

当前问题：

- 侠义保护其他角色、觉醒后免费援助他人的方向已生效。
- 海流护航仍未允许甚平选择自己。
- 拥有护盾时的鱼人空手道没有忽略防具。
- 完整补上两项能力后，甚平可能由当前健康区上升到偏强区。

调整要求：

1. 海流护航允许选择自己或其他存活角色。
2. 未觉醒时无论目标是谁均弃1张；觉醒后以他人为目标免费，以自己为目标仍弃1张。
3. 拥有至少1点护盾时，普通突击忽略防具；不影响武赖贯和其他招牌技。
4. 侠义保持每轮一次，只保护距离1内其他角色，并允许人类放弃。
5. AI在2V2只给队友护盾；军八按公开身份和行为信任度选择。
6. 体力、武赖贯伤害和护盾数量暂不调整。

复测门槛：完整补齐后若胜率高于60%，鱼人空手道改为命中时消耗1点护盾以忽略防具；未越界时不增加消耗。

## 8. 测试与验收标准

### 8.1 公共机制

- [ ] `cardResolved`只在卡牌主体效果完成后发送。

## 9. 建议修改范围

- `src/packs/one-piece.js`：梦想条件、觉醒收益、主动技、被动技、招牌技和角色限次状态。
- `src/engine.js`：卡牌事件时点、攻击修正、转移牌事件、首回合摸牌、裂隙收束、AI评分和存档状态。
- `src/data.js`：同步路飞、索隆及所有发生规则变化的角色文字。
- `src/app.js`：一次性强化、梦想条件、裂隙收束和隐藏牌可见性。
- `test/engine.test.js`：保留基础系统和跨扩展包回归。
- `test/one-piece.test.js`：建议新建，集中覆盖十名角色的正确性和多步选择。
- `scripts/balance-simulation.mjs`：首行动字段、纯包/混合池切换、觉醒与长局数据。

## 10. 修改原则

1. 角色文字与实现必须同时修改，不能继续依赖“实际效果已经削弱但文案没变”的隐性平衡。
2. 先修机制再运行完整样本，完整样本之前不执行P2数值调整。
3. 纯包和混合池必须同时达标；不以单一环境的39%或61%直接决定加减数值。
4. 梦想是伟大航路的公共特色，低觉醒角色优先调整条件和AI，不优先增加战斗数值。
5. 长局问题按“AI资源循环 + 全局保险”双层处理，不能只依靠护盾上限。
6. 每名角色每轮最多改动一个主要强度来源，避免无法判断哪项修改造成胜率变化。
7. 所有随机样本保留种子，修正前后使用同一批种子进行配对比较。
8. 最终数值仍需真人2V2和军八记录校准，AI模拟用于发现极端值和机制异常。
