# 《动漫杀》忍界初阵与基础系统急需调整需求文档

日期：2026-09-08  
建议目标版本：0.2.0
性质：平衡诊断、机制修正与基础系统调整需求，不包含本轮代码实现

## 1. 调整目标

在继续制作新扩展包之前，先修正“忍界初阵”已确认的技能结算问题，降低我爱罗和自来也的异常强度，改善樱、鹿丸、卡卡西和大蛇丸的可用性，并处理2V2先手阵营优势、隐藏身份AI读取真实阵营、护盾无限累积和极端长局等基础问题。

本轮不增加角色、不调整基础牌堆数量、不重做游戏模式，也不以一次AI胜率直接代替真人平衡结论。

## 2. 结论摘要

- 我爱罗属于必须立即削弱的异常角色，四座位归一化胜率为91.2%。
- 自来也属于明显超模角色，四座位归一化胜率为69.5%。
- 鸣人、佐助、雏田整体处于可接受区间，暂不应直接调整数值。
- 樱、卡卡西明显偏弱；鹿丸和大蛇丸也偏弱，但其中包含技能状态、能量链和AI决策问题，应先修正确性再决定数值补强。
- 2V2苍队在5000局纯忍界对局中胜率57.08%，绯队42.92%，固定由0号座位先行动造成显著阵营偏差。
- 军八2000局中破界阵营胜率63.85%、界主阵营33.65%、独行者2.50%；在修正隐藏身份AI作弊前，不应直接修改身份数量或胜利条件。
- 全部现有66项自动化测试通过，但测试绿灯没有覆盖跨回合强化失效、卡卡西核心能量链、可选技能被自动消耗以及大规模座位平衡。

## 3. 测试口径

### 3.1 已执行测试

1. 执行`npm test`，66项测试全部通过。
2. 混合28名角色池：每名忍界角色两批、每批200局AI 2V2，共4000局，用于与伟大航路测试保持相同口径。
3. 纯“忍界初阵”角色池：每名角色固定在苍队0号座位400局，共4000局，排除伟大航路当前已知技能缺陷的干扰。
4. 四座位对照：每名角色在0、1、2、3号座位分别150局，共6000局；归一化胜率取四个座位胜率的算术平均。
5. 技能使用频率：每名角色200局，共2000局，记录主动技与招牌技的平均使用次数。
6. 军八角色样本：每名忍界角色100局，共1000局，检查终局和身份表现。
7. 基础模式样本：纯忍界角色池5000局2V2及2000局军八，共7000局。

本次累计约24000局AI模拟。所有模拟均使用可复现伪随机种子，AI对局最多推进4000步，军八基础样本最多推进8000步。

### 3.2 结果解释限制

- AI胜率同时受到角色强度、AI是否会使用技能、座位和队友组合影响。
- 四座位归一化可以降低先手阵营偏差，但不能替代真人对局。
- “明显超模”可以通过极端且稳定的胜率确认；“偏弱”角色必须先修复机制和AI，再决定是否增加数值。
- 军八是非对称身份模式，三个阵营不要求各占三分之一；当前结果用于发现异常，不作为最终平衡目标。

## 5. 已确认的机制问题

### F-01 “下一次攻击”状态被回合开始错误清空

受影响角色至少包括鸣人、樱和鹿丸。

- 鸣人消耗分身进行防御后，代码把强化记录在`turnFlags.nextAttackBonus`。
- 若分身在其他角色回合被消耗，鸣人下回合开始会重建`turnFlags`，强化在鸣人能够攻击前消失。
- 最小探针确认：实际消耗分身后强化为`true`，进入鸣人下个回合后变为`false`。
- 樱在其他角色受伤时解放基础百豪牌，也可能以同样方式丢失“下一次攻击伤害+1”。
- 鹿丸的`shadowNeckTarget`在棋子回合触发，但鹿丸下回合开始会被清空；正常行动顺序下很难真正使用强化。

调整要求：将“直到下一次攻击被使用”的强化改为玩家持久状态，只在成功声明对应突击、角色退场或技能明确失效时清除，不得在普通回合开始时统一清除。

### F-02 卡卡西的标准能量链无法闭合

- 拷贝忍术消耗1能量。
- 神威雷切消耗4能量。
- 普通角色能量上限为4，拷贝牌又会在本回合结束时消失。
- 最小探针确认：4能量发动拷贝忍术后剩余3能量，已持有合法拷贝牌和招牌技目标，但神威雷切返回“能量不足”。
- 当前只有备用电池、回合中额外获得能量等少数情况可以完成核心连招，导致招牌技平均仅使用0.39次/局。

调整要求：神威雷切基础消耗由4降为3，使“1能量拷贝忍术 + 3能量神威雷切”在标准4能量上限内成立。拷贝牌仍在回合结束时消失。

### F-03 文本中的可选防御被自动消耗

- 樱的百豪保护在伤害结算中会自动消耗对应类别百豪牌，人类玩家没有放弃选项。
- 大蛇丸的蛇蜕会自动消耗第一张实验牌，人类玩家没有保留实验牌承受伤害的选项。
- 最小探针确认两者均在没有`pendingChoice`的情况下立即消耗资源。

调整要求：凡技能文本使用“可”的防御或减伤效果，都必须给人类玩家“发动/不发动”选择。AI仅在防止致命伤害、阻止至少2点伤害或资源价值明确为正时自动发动。

### F-04 我爱罗的绝对防御规则与强度边界不清

- 绝对防御当前会拦截通过统一攻击流程结算的招牌技，不只普通突击。
- 人类玩家第一次弹出绝对防御后即写入本轮已触发标记；即使选择不发动，本轮也不能再次选择。
- 一次发动同时产生“取消整次攻击、我爱罗弃1、攻击者弃1”，可以用一张低价值牌取消2至3点强袭并额外破坏攻击者资源。
- 该角色四座位归一化胜率91.2%，说明问题远超正常随机波动。

调整要求：第一轮调整先移除“攻击者还须弃1张牌”；绝对防御仅在玩家实际选择发动后记录本轮已使用。第一轮复测后若归一化胜率仍超过60%，再将其限制为只取消`origin === "attack"`的普通突击。

### F-05 自来也招牌技包含未写明的不可介入

仙法·五右卫门的代码对所有目标固定设置`skipIntervene: true`，但角色文本没有说明该效果不可被强制介入。该技能同时可以攻击两名角色，每名基础造成2点伤害并需要2张防御，共鸣目标还会再增加伤害和穿甲。

调整要求：移除五右卫门的无条件不可介入。第一目标保持2伤害、2防御；第二目标改为1伤害、1防御。仙术共鸣仍只能强化其中一名目标，蛤蟆束缚仍只对被束缚目标额外增加1张防御需求。

### F-06 忍界技能绕过统一装备事件

佐助的天手力直接交换装备字段，卡卡西神威雷切和大蛇丸不尸转生也直接移除或设置装备。这些路径没有全部经过统一的`equipmentChanged`事件，可能导致弗兰奇的梦想航迹、可乐能源以及未来依赖装备变化的角色漏触发。

调整要求：所有装备进入、离开、交换、替换和被抹除操作统一调用一个装备变更入口；入口负责刷新能量上限、派发事件和记录来源。装备转移是否触发“从手牌装备”收益应由事件字段区分，而不是跳过整个装备变化事件。

### F-07 卡牌事件生命周期命名与实际时点不一致

通用出牌流程在牌离开手牌后、反制和实际效果结算前就发送`cardResolved`。这会使梦想、能量和未来扩展包技能把被反制或未产生效果的牌视为已经结算。

调整要求：拆分为`cardDeclared`、`cardCancelled`和`cardResolved`。只有牌没有被取消且主体效果已经完成时发送`cardResolved`；多目标牌在整张牌处理结束后只发送一次整牌结算事件，单个目标结果通过子事件表达。

### F-08 隐藏身份AI直接读取真实阵营

军八AI通过`isAlly`筛选敌人、队友和技能目标，即使身份仍未公开也能准确协作或集火。独行者则把所有人视为敌人并优先攻击低体力目标，容易过早击杀界主、直接帮助破界阵营获胜。

调整要求：军八AI只能使用公开身份和行为推测形成的阵营倾向。未公开角色不得按真实`roleId`参与目标评分；独行者在破界者未基本清除前应降低攻击界主的优先级。

### F-09 护盾没有上限，存在极端长局

混合角色对局中复现了存活角色护盾55和66的状态，并出现4000步、560轮仍未结束的对局。纯忍界5000局2V2虽然全部结束，但最大达到441轮，说明引擎缺少对可无限累积防御资源的安全边界。

调整要求：增加全局护盾上限3点，所有护盾获取统一执行`min(3, shield + amount)`。先通过上限修复长局；若10000局复测仍出现超过80轮的对局，再启用第40轮开始的“裂隙收束”：每名角色回合结束失去1点体力，此损失绕过护盾但允许正常重伤救援。

## 6. 角色调整需求

### 6.1 漩涡鸣人

优先级：P0正确性，数值暂不调整。

- 修复分身防御产生的下一次攻击强化跨回合丢失。
- 强化必须持续到鸣人下一次普通突击实际声明时；不能被招牌技或无效目标错误消耗。
- AI保留最后一张治疗牌或应变牌的价值应高于制造分身，避免无条件选择第一张基础牌。

### 6.2 我爱罗

优先级：P0削弱。

- 绝对防御移除攻击者弃牌惩罚，只有实际发动才占用每轮次数。
- 砂缚改为目标二选一：弃1张手牌，或下回合少摸1张；无手牌时自动选择少摸1张，不再额外受到1点直接伤害。
- 两种选择都会保留砂瀑追葬标记。
- 砂瀑大葬第一轮不改，待前两项调整后复测。

### 6.3 春野樱

优先级：P0正确性、P1观察性补强。

- 修复基础百豪牌的下一次攻击强化跨回合丢失。
- 百豪保护增加发动选择，AI不得为了普通1点非致命伤害随意消耗关键牌。
- AI只有在至少拥有1张百豪牌时才优先发动百豪之术；没有百豪牌时不得把4点能量只换成一次普通攻击加伤。
- 第一轮不直接增加体力或伤害。完成上述修正后若四座位归一化胜率仍低于42%，将百豪区上限由2张提高到3张，仍要求类别不同。

### 6.4 奈良鹿丸

优先级：P0正确性。

- 将战术预读的强化目标改为持久字段，直到鹿丸对该棋子发动下一次普通突击后清除。
- 即使棋子已经位于本轮行动队列末尾、无法继续后移，仍应获得下一次攻击强化；仅跳过队列交换。
- 角色文本补充“战术预读每轮限一次”，与现有`roundFlags.foresight`一致。
- 完成修复后再判断是否需要数值补强。

### 6.5 宇智波鼬

优先级：P1观察。

- 当前归一化胜率45.8%，暂不调整体力、能量和伤害。
- 修复军八AI读取真实阵营后重新测试乌鸦替身的目标选择。
- AI只有在转移后预期收益高于保留幻象时才消耗虚假伏笔，不得默认自动发动。

### 6.6 宇智波佐助

优先级：P1 AI与事件一致性。

- 当前归一化胜率47.3%，暂不调整数值。
- 天手力AI按装备价值差选择槽位，避免把高价值装备无条件换给敌人。
- 天手力交换必须派发双方的装备离开和进入事件。

### 6.7 旗木卡卡西

优先级：P0可用性修复。

- 神威雷切消耗由4能量降为3能量。
- 拷贝忍术的弃牌堆候选范围不再静默限制为最近8张；若保留性能限制，角色说明必须明确“最近8张”。本次建议直接允许全部合法弃牌。
- AI发动拷贝忍术前应评估本回合能否使用拷贝，准备神威雷切时优先保留3点能量。
- 神威雷切移除装备时必须派发装备变化事件。

### 6.8 日向雏田

优先级：P1观察。

- 四座位归一化后为48.8%，暂不因固定0号座位的62.5%结果削弱。
- 修复2V2先手阵营后重新测试。
- 军八AI不能利用白眼之外的真实身份数据；白眼看到的手牌和伏笔可以进入AI公开知识。

### 6.9 自来也

优先级：P0削弱。

- 五右卫门允许正常强制介入。
- 第一目标保持2伤害、需要2张防御。
- 第二目标改为1伤害、需要1张防御。
- 共鸣只强化一个目标；束缚只增加被束缚目标的防御需求。
- 第一轮保留蛤蟆口束缚和仙术印获取速度，调整后若归一化胜率仍高于60%，再将蛤蟆口束缚改为每轮一次而非每回合一次。

### 6.10 大蛇丸

优先级：P0正确性、P1 AI。

- 蛇蜕增加“消耗实验牌/承受伤害”选择。
- AI根据当前体力、伤害量和实验牌类型决定是否蛇蜕，不再自动消耗第一张实验牌。
- 咒印实验的样本选择应考虑手牌价值，目标选择应考虑其公开的出牌倾向；军八中不得读取隐藏手牌或真实阵营。
- 不尸转生按实际需要选择基础、策略或装备实验牌，不得固定选择第一张。
- 第一轮不直接增加体力。修复AI和可选结算后再评估其36.8%的归一化胜率。

## 7. 基础游戏调整需求

### B-01 随机化2V2先手

当前排位2V2没有界主，`anchorSeat`固定为0，导致苍队长期先行动。5000局纯忍界样本中苍队胜率57.08%。

要求：开局从四个座位中等概率选择首行动座位，并把结果写入存档和命令日志，确保恢复后完全确定。验收时分别统计四个首行动座位，苍、绯总体胜率均应处于48%至52%。

### B-02 为AI建立角色技能评分

当前AI以55%随机概率发动主动技，并经常选择第一个合法目标或第一张合法牌。这会放大我爱罗这类“随便用也强”的角色，同时低估樱、卡卡西和大蛇丸等需要资源规划的角色。

要求：在通用AI决策中加入目标收益、资源成本、致命伤害、队友保护、下一步招牌技和隐藏信息合法性评分。角色只提供少量特定修正，不为每名角色复制完整AI流程。

### B-03 军八AI知识隔离

要求：建立AI可见信息接口。所有目标选择只能读取该接口，不得直接读取未公开角色的`roleId`、隐藏手牌或真实伏笔。记录每个角色对其他角色的阵营倾向，依据攻击、治疗、护盾、交牌和身份公开更新。

### B-04 统一“可发动”交互

要求：伤害、弃牌、防御、替身和资源消耗中的可选技能使用同一选择协议。人类玩家始终可以放弃；AI通过评分选择；存档必须能在该选择窗口中恢复。

### B-05 统一临时状态生命周期

要求：状态明确区分“本回合”“本轮”“直到下回合开始”“直到下一次攻击”。禁止用统一重建`turnFlags`的方式承载跨回合状态。角色详情必须显示仍然有效的待触发强化及其目标。

### B-06 增加平衡与长局遥测

每局至少记录：模式、随机种子、四个角色、座位、阵营、胜者、轮数、步数、主动技次数、招牌技次数、伤害、治疗、护盾获取、取消牌次数和身份公开轮次。批量测试输出JSON和Markdown摘要，便于版本间比较。

## 9. 测试与验收标准

### 9.1 角色正确性

- [ ] 鸣人在其他角色回合消耗分身后，下回合普通突击仍获得伤害加成。
- [ ] 樱在其他角色回合解放基础百豪牌后，下回合普通突击仍获得伤害加成。
- [ ] 鹿丸的战术预读强化能够跨回合保留，并在攻击对应棋子后清除。
- [ ] 卡卡西在4能量时可以依次发动拷贝忍术和神威雷切。
- [ ] 樱和大蛇丸均可放弃自动减伤，选择窗口可被存档恢复。
- [ ] 我爱罗放弃绝对防御不会消耗本轮次数。
- [ ] 五右卫门可以被强制介入，第二目标按1伤害、1防御结算。
- [ ] 忍界角色引起的装备变化会正确触发伟大航路装备事件。

### 9.2 平衡与终局

- [ ] 每名忍界角色至少完成四个座位各500局纯包2V2。
- [ ] 四座位归一化后没有角色高于60%或低于40%。
- [ ] 苍队与绯队在至少10000局中胜率均处于48%至52%。
- [ ] 至少99.9%的2V2对局在4000步内结束。
- [ ] 2V2对局轮数P99不超过30轮，护盾不超过3点。
- [ ] 超过80轮的对局为0；如未达到，启用裂隙收束后重新验收。

### 9.3 军八

- [ ] 未公开身份不参与AI敌我筛选。
- [ ] AI日志能够解释一次目标判断使用了哪些公开信息。
- [ ] 修复知识隔离后至少完成10000局军八，再决定是否调整身份数量、公开收益或胜利条件。

## 10. 建议修改范围

- `src/engine.js`：临时状态、攻防选择、2V2首行动座位、装备事件、卡牌事件时点、AI信息与决策。
- `src/data.js`：我爱罗、自来也、卡卡西及鹿丸的最终技能文字和数值。
- `src/app.js`：可选技能窗口、持久状态提示和AI信息说明。
- `test/engine.test.js`：角色正确性与事件生命周期回归。
- `test/balance-simulation.test.js`：短样本、四座位、固定种子的平衡门禁。
- `scripts/balance-report.mjs`：完整批量对局与Markdown报告生成。

## 11. 调整原则

1. 先修错误，再改数值；不得用增加体力或伤害掩盖技能没有生效。
2. 一轮只改一个主要强度来源；我爱罗和自来也第一次削弱后必须重新测试再决定第二刀。
3. 固定座位胜率不能单独用于削弱角色，必须同时查看四座位归一化结果。
4. AI模拟用于发现极端问题，最终细调至少加入真人2V2和军八记录。
5. 所有新事件和状态必须支持确定性存档恢复。
