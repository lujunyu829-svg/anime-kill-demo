# 《动漫杀》伟大航路与基础系统急需调整需求文档

日期：2026-09-08  
建议目标版本：0.2.0
性质：平衡诊断、机制修正与基础系统调整需求，不包含本轮代码实现

## 1. 调整目标

在继续增加角色或制作第三个扩展包之前，先让“伟大航路”十名角色的实际结算与设计文案一致，修复梦想航迹、觉醒收益、谎言、援护、封存和护航等核心机制，并处理布鲁克与路飞的异常强度、乌索普与甚平的异常低胜率，以及护盾无限累积、2V2先手偏差和军八AI读取真实阵营等基础问题。

本轮不增加角色、不调整基础牌堆、不重做梦想航迹规则，也不根据当前一次AI胜率直接增减角色体力或伤害。伟大航路现阶段存在大量“技能未实现或实现与文案相反”的问题，必须先修正确性，再进行第二轮数值平衡。

## 2. 结论摘要

- 布鲁克四座位归一化胜率76.7%，属于明显超模；最主要原因是尚未觉醒也能触发一次免死，且“灵魂乐章”额外附加了文案没有的少摸牌。
- 路飞四座位归一化胜率68.8%，明显偏强；当前“见闻色”不是按牌堆顶类别结算，而是每轮免费进行一次50%随机闪避，必须优先修正。
- 娜美四座位归一化胜率60.1%，处于偏强观察线；但顺风航线尚未生效、觉醒航海术又错误允许拿两张同类别牌，暂时不能直接用数值削弱。
- 乌索普四座位归一化胜率30.7%、觉醒率0%，核心“谎言”没有接入出牌结算，目标出牌时既不会弃牌也不会取消牌。
- 甚平四座位归一化胜率30.5%，虽然觉醒率78.7%，但侠义错误地保护自己而非其他角色，觉醒海流护航仍会弃牌，鱼人空手道也没有穿甲。
- 罗宾36.5%、弗兰奇39.7%偏弱；二者分别受到封存目标和归还时点错误、装备AI与护盾长局污染影响，应先修机制与AI。
- 索隆49.8%、山治51.3%、乔巴53.3%的归一化胜率暂时正常，但觉醒率只有10.3%、12.5%和7.5%，且均有多个技能未接入，不能据此认定设计完整。
- 梦想航迹的公共规则本身能够做到每轮最多推进1点、到3点立即觉醒；主要问题在各角色事件是否正确派发，以及觉醒收益是否真的生效。
- 纯伟大航路5000局2V2出现6局未在4000步内结束，单局最高576轮、211护盾；2000局军八最高1098轮、439护盾，必须增加护盾上限。
- 当前测试主要覆盖扩展包数据、通用航迹和索隆动态招牌技消耗，远未覆盖每名角色的完整结算。

## 3. 测试口径

### 3.1 已执行测试

1. 执行现有自动化测试，确认当前回归基线。
2. 纯“伟大航路”角色池：每名角色固定在苍队0号座位400局，共4000局。
3. 四座位对照：每名角色在0、1、2、3号座位分别150局，共6000局；归一化胜率取四个座位胜率的算术平均。
4. 技能与航迹样本：混合28人角色池和纯伟大航路角色池各2000局，记录主动技、招牌技、航迹进度、觉醒率和觉醒轮次。
5. 基础模式样本：纯伟大航路角色池5000局2V2及2000局军八，共7000局。
6. 针对十名角色执行最小状态探针，直接验证技能文本中的关键边界。

本次累计约21000局AI模拟。2V2最多推进4000步，军八最多推进8000步；所有批量模拟均使用可复现伪随机种子。

### 3.2 结果解释限制

- 当前AI通常以固定概率发动主动技，并经常选择第一张牌或第一个合法目标，会低估需要规划资源、选择牌序或保护队友的角色。
- 四座位归一化能降低固定先手的污染，但不能替代真人对局。
- 当前很多技能没有生效，因此本报告的胜率用于确定修复优先级，不作为最终数值定案。
- 军八为非对称身份模式，三个阵营不要求各占三分之一；在修复隐藏身份AI作弊前，不调整身份数量和胜利条件。

## 5. 已确认的机制问题

### OP-F01 布鲁克未觉醒也会触发免死

- 当前濒死事件只检查角色是布鲁克、免死尚未使用和伤害来源合法，没有检查`dreamState.awakened`。
- 最小探针确认：未觉醒布鲁克受到致命伤害后仍保留1体力、弃空手牌并清空能量。
- 这项错误直接提供了完整觉醒收益，是其76.7%归一化胜率的首要污染源。

调整要求：只有已经觉醒且`reviveUsed === false`时才能触发“黄泉归来”。失去体力不能触发；伤害触发后设置一次性标记。角色退场和存档恢复均不得重复获得机会。

### OP-F02 乌索普“谎言”没有接入出牌流程

- 谎言可以被暗置并记录目标，但目标使用下一张非响应牌时没有任何结算钩子。
- 最小探针确认：目标正常打出策略牌、获得效果，谎言仍留在乌索普特殊牌区。
- 诈术回收、梦想推进、狙击王距离和狼草消耗谎言后的收益因此都不能形成完整玩法，觉醒率为0%。

调整要求：在非响应牌声明后、支付和实际效果结算前触发谎言。目标选择“弃另一张牌继续”或“取消当前牌”；完成选择后移除谎言，并分别触发乌索普摸1或获得1能量。当前牌被取消时不得触发`cardResolved`。目标没有另一张可弃牌时自动取消。

### OP-F03 甚平“侠义”保护了错误对象

- 当前伤害前事件检查的是受伤者本人是否为甚平，因此只会在甚平自己受伤时自动弃牌减伤。
- 文案要求甚平保护距离1内的其他角色，不允许保护自己。
- 当前结算自动消耗第一张基础牌，没有“发动/不发动”选择。
- 海流护航目标列表排除了自己，觉醒后援助他人仍然弃牌；均与文案相反。

调整要求：伤害前搜索距离受伤者1以内、存活且本轮未发动侠义的甚平，由甚平选择是否弃1张基础牌令该次伤害-1。目标必须是其他角色。海流护航允许选择任意存活角色；觉醒后以他人为目标不弃牌，以自己为目标仍弃1张牌。

### OP-F04 通用“下一次突击忽略防具”只对特定旧角色生效

- 路飞觉醒五档、索隆弃装备发动三刀流和乌索普消耗谎言后都会写入`nextAttackIgnoreArmor`。
- 当前攻击结算只在特定旧角色分支读取这一标记。
- 最小探针确认：觉醒路飞发动五档后攻击有防具目标，防具正常减伤，忽略防具标记也没有被消耗。
- 山治黑足、甚平鱼人空手道和索隆阿修罗也没有通过统一穿甲规则结算。

调整要求：攻击声明统一计算`ignoreArmor`，来源包括一次性状态、招牌技参数和角色持续条件；一次性状态只在合法攻击声明时消耗。不得继续通过角色ID特判读取通用攻击标记。

### OP-F05 娜美航海术和卡牌生命周期不符合设计

- 觉醒航海术可以连续选择两张同类别牌，而文案要求类别不同；不存在两种类别时应只获得1张。
- 多张牌逐张`unshift`会反转玩家选择的置顶顺序。
- 航海术结束后没有设置顺风航线，下一张单目标策略既不获得距离收益，被反制后也不会返回手牌。
- 引擎在卡牌效果和反制完成前就派发`cardResolved`，导致气象棒、梦想和未来技能可能把被取消的牌视为成功结算。

调整要求：觉醒选择第二张时只展示不同类别候选；无候选直接结束。置顶牌按玩家选择顺序保持。航海术完成后设置一次性顺风状态，在下一张单目标策略声明时生效，并在结算或取消后清除；被反制时原牌返回娜美手牌。

### OP-F06 多名角色的常驻技或触发技没有接入

已确认缺失包括：

- 路飞“越战越勇”没有在每回合首次失去体力后产生下一次突击加伤。
- 索隆“剑士本能”的武器距离额外+1和首次突击被完全防御摸1没有生效。
- 索隆三刀流强化突击没有推进梦想。
- 山治“黑足”的距离+1和忽略防具没有生效；治疗他人后也没有产生援护反击状态。
- 乔巴“诊断”没有在首次治疗他人后令双方摸牌，“毛皮强化”没有加入防御牌选择。
- 罗宾觉醒后仍只查看1张隐藏牌，而非展示2张并选择其中1张。
- 布鲁克“黄泉寒气”会在同一回合的每次突击伤害后施加少摸牌，而非首次。
- 甚平“鱼人空手道”没有在拥有护盾时提供穿甲。

调整要求：为每项技能增加独立回归测试。触发频率必须对应“每回合首次”或“每轮首次”，不得用同一个临时标记混用两种生命周期。

### OP-F07 索隆阿修罗的觉醒收益和文案不一致

- 阿修罗命中后摸1当前对未觉醒索隆也生效。
- 阿修罗没有实际忽略防具。
- 代码固定设置不可介入，但角色文案只写了2伤害、2防御和忽略防具。
- 三刀流强化突击没有推进梦想，导致其觉醒率只有10.3%。

调整要求：未觉醒阿修罗消耗4且命中不摸牌；觉醒后动态消耗3且命中摸1。阿修罗始终忽略防具并允许正常强制介入。三刀流产生的强化被合法突击声明并结算时推进梦想，不要求造成伤害。

### OP-F08 乔巴净化一次清除了全部异常

- 觉醒医术当前会把毒、少摸牌、能量封锁和全部招牌技封锁同时清零。
- 文案要求在“1层毒、少摸牌、能量封锁或1层招牌技封锁”中清除一项。
- 满体力但有异常的目标已能进入目标列表，这部分方向正确。

调整要求：治疗结算后若目标存在异常，弹出一次净化选择。毒和招牌技封锁各减少1层；少摸牌清零1次状态；能量封锁解除。没有异常时不弹窗。人类和AI均只能选择一项。

### OP-F09 罗宾搜查存在空目标、查看数量和归还时点错误

- 目标只持有响应牌时仍被列为合法目标，罗宾会先支付能量并占用主动技，随后什么都没有发生。
- 觉醒后仍只随机展示1张牌。
- 封存牌记录了封存者，当前归还逻辑在罗宾的下回合开始执行，而文案要求在被封存目标的下回合开始归还。
- 历史学者没有独立的每轮首次标记，未来一次效果查看多张牌时可能重复摸牌。

调整要求：目标必须至少有1张非响应手牌；觉醒后从目标随机取最多2张非响应手牌公开给罗宾，再由罗宾选择其中1张作为可封存对象。封存状态记录`returnAtPlayerId`，在目标下回合开始归还。历史学者每轮最多摸1张。

### OP-F10 弗兰奇觉醒工坊和装备事件不完整

- 觉醒改造工坊直接装备新装备时，替换下来的旧装备进入弃牌堆，没有返回手牌。
- 可乐能源和梦想依赖`equipmentChanged`，但部分装备进入、离开、交换或抹除路径没有统一派发该事件。
- 弗兰奇对局中可反复回收装备和获得护盾，纯包样本出现超过200护盾的极端状态。

调整要求：觉醒工坊替换装备时将旧装备返回弗兰奇手牌；所有装备变化统一经过装备入口，事件明确`ownerId`、`sourceId`、`slot`、`enteredCard`和`leftCard`。同一次替换只让可乐能源和梦想各检查一次每轮限制。

### OP-F11 布鲁克灵魂乐章附带未写明的控制

当前灵魂乐章在双方摸牌、目标弃牌后，还会把目标少摸牌状态至少设为1。设计文案只要求“双方各摸1，然后目标弃1”；少摸牌应来自黄泉寒气或箭尾斩。

调整要求：移除灵魂乐章附带的少摸牌，只保留摸后弃牌和梦想推进。黄泉寒气增加每回合首次标记；箭尾斩即使完全防御仍施加少摸牌，保持不变。

### OP-F12 军八中的“敌方”效果会读取隐藏真实阵营

- 巨大树通过`isAlly`筛选所有真实敌人，即使身份尚未公开。
- 通用AI也使用真实阵营选择主动技、招牌技和卡牌目标。
- 这既泄露隐藏身份，也让伟大航路角色在军八中的胜率无法作为平衡依据。

调整要求：2V2中的“敌方”继续按公开队伍结算；军八若卡牌需要玩家指定敌人，由玩家基于公开信息选择；“全体敌方”在隐藏身份规则下应改为“所有其他角色”，除非规则明确允许识别真实阵营。AI只能读取公开身份和行为推测。

## 6. 角色调整需求

### 6.1 蒙奇·D·路飞

优先级：P0正确性、P1复测后平衡。

- 将见闻色改为确定的牌堆顶检定：基础牌作为1张防御弃置，其他牌收入路飞手牌；移除当前50%随机闪避。
- 实现越战越勇：每回合首次实际失去体力后，下一次普通突击伤害+1；效果可以跨过其他角色回合，但只在合法突击声明时消耗。
- 修复觉醒五档的距离无限和下一次突击忽略防具。
- 二档和突击命中仍按每轮最多推进1点航迹，不重复累计。
- 第一轮不直接削弱二档或五档。完成上述修复后若四座位归一化胜率仍高于60%，优先将见闻色获得的非基础牌改为置于牌堆底，而不是再提供额外手牌。

### 6.2 罗罗诺亚·索隆

优先级：P0正确性。

- 实现武器攻击距离额外+1。
- 每回合首次普通突击被完全防御后摸1张。
- 三刀流强化突击结算时推进梦想，阿修罗结算时也可推进，但同轮总计仍只能1点。
- 阿修罗始终忽略防具并允许强制介入；只有觉醒后才降低为3能量并在命中后摸1。
- 第一轮不调整体力和伤害。修复后目标觉醒率为25%至60%。

### 6.3 娜美

优先级：P0正确性、P1强度观察。

- 修复航海术的异类别选择和置顶顺序。
- 实现顺风航线的无视距离、被反制返还手牌和一次性状态清理。
- 雷云宙斯必须让目标主动选择“弃2张牌”或“受到2点策略伤害”；手牌不足2张时只能选择伤害。
- 气象棒和梦想只在牌真正结算后触发，被取消或反制的牌不触发。
- 修复后若归一化胜率仍高于60%，先将气象棒改为每轮首次，而不是降低基础手牌上限或航海术看牌数。

### 6.4 乌索普

优先级：P0核心玩法修复。

- 完整实现谎言的出牌前检定、弃牌继续、取消当前牌、谎言移除和诈术回收。
- 狙击王对谎言目标的普通突击和单目标策略无视距离。
- 狼草只有实际消耗该目标的谎言时才忽略防具且不可介入。
- 每轮首次因自己的效果令他人弃牌或取消牌时推进梦想。
- 觉醒后每轮首次触发的谎言牌返回乌索普手牌；其他已触发谎言正常弃置。未触发谎言在乌索普下回合开始时弃置。
- 核心机制修复前不得通过增加体力、起始手牌或伤害补强。

### 6.5 文斯莫克·山治

优先级：P0正确性。

- 未装备武器时，普通突击距离+1并忽略防具。
- 每回合首次令他人实际回复，或令他人获得自己交出的牌后，设置一次援护反击。
- 援护反击持续到下一次普通突击或魔神风脚声明：普通突击无视距离且额外需要1张防御；魔神风脚改为不可介入。使用后清除。
- 海上餐厅觉醒后目标摸1张，保持现有方向。
- 增加“交出牌”统一事件，避免未来只能通过治疗推进梦想。

### 6.6 托尼托尼·乔巴

优先级：P0正确性。

- 实现诊断：每轮首次令其他角色实际回复后，乔巴与目标各摸1张。
- 实现毛皮强化：每轮首次需要防御时，可选择一张非响应基础牌当作1张防御；允许放弃发动。
- 觉醒医术只净化一个异常或一层状态，并为人类提供明确选择。
- 只有产生实际回复时推进梦想；仅净化满体力目标不会推进。
- 怪物强化获得护盾时遵守全局护盾上限。

### 6.7 妮可·罗宾

优先级：P0正确性、P1 AI。

- 搜查目标必须持有非响应手牌，避免空耗能量。
- 觉醒后展示两张随机非响应牌，由罗宾选择其中一张，再决定是否弃同类别牌封存。
- 封存牌在原持有者下回合开始归还，不在罗宾回合归还。
- 历史学者每轮首次查看隐藏手牌或伏笔后摸1张，后续查看不重复摸牌和推进梦想。
- 巨大树在2V2只影响敌队；军八改为影响所有其他存活角色，不读取隐藏阵营。
- 修复后若归一化胜率仍低于40%，再考虑将百花搜查的能量消耗取消；第一轮不直接改数值。

### 6.8 弗兰奇

优先级：P0长局与事件修复、P1 AI。

- 觉醒改造工坊直接装备时，替换下来的旧装备返回手牌。
- 可乐能源和梦想只对自己装备区的实际进入或离开生效，每轮各限一次。
- 弗兰奇将军分别选择武器与防具，不存在的类别各摸1，最后获得护盾；全部护盾遵守上限。
- AI按装备价值和当前槽位选择回收、替换与招牌技，避免反复用高价值装备替换同级装备。
- 先处理护盾上限和AI；若归一化胜率仍低于40%，再把改造工坊的1能量消耗改为“每轮首次发动免费”。

### 6.9 布鲁克

优先级：P0正确性与削弱。

- 免死严格要求已经觉醒，每局限一次，仅伤害可触发。
- 灵魂乐章移除额外少摸牌。
- 黄泉寒气改为每回合首次普通突击造成伤害后施加少摸牌。
- 灵魂出窍每轮首次策略伤害-1，保持不变。
- 箭尾斩即使完全防御仍令目标下回合少摸1，保持不变。
- 完成三项修正后再复测；若归一化胜率仍高于60%，将灵魂乐章限制为每轮一次，而不是削弱觉醒免死。

### 6.10 甚平

优先级：P0核心玩法修复。

- 海流护航允许自己或其他存活角色成为目标。
- 未觉醒或以自己为目标时弃1张牌；觉醒后以他人为目标不弃牌。
- 侠义只保护距离1内其他角色，每轮一次，可选择不发动。
- 拥有至少1点护盾时，普通突击忽略防具。
- AI只把海流护航优先用于队友，不得在2V2给敌人护盾；军八按公开信任度判断。
- 核心机制修复前不增加体力、护盾数或武赖贯伤害。

## 7. 基础游戏调整需求

### B-01 随机化2V2首行动座位

纯伟大航路5000局2V2中，已结束的4994局里苍队胜率59.07%、绯队40.93%。当前没有界主时固定0号座位先行动，已经严重污染角色固定座位胜率。

要求：开局从四个座位等概率选择首行动座位，并写入存档与命令日志。至少10000局复测中，苍、绯队总体胜率均应处于48%至52%。

### B-02 设置全局护盾上限

纯伟大航路样本出现211护盾、576轮的2V2和439护盾、1098轮的军八；6局2V2未在4000步内结束，1局军八未在8000步内结束。

要求：护盾统一上限为3点，所有角色、装备、招牌技和卡牌必须调用同一个护盾获取入口。达到上限后仍可记录“尝试给予护盾”，但不得视为实际数值变化；甚平梦想只在他人护盾实际增加时推进。

### B-03 修正卡牌事件生命周期

要求：把卡牌事件拆分为`cardDeclared`、`cardCancelled`和`cardResolved`。谎言在声明后、主体效果前触发；反制或谎言取消发送`cardCancelled`；只有主体效果处理结束才发送`cardResolved`。梦想和气象棒不得依赖含义错误的早期事件。

### B-04 建立统一攻击修正管线

要求：普通突击和攻击型招牌技统一计算伤害、所需防御、距离、忽略防具、是否允许介入和完成回调。角色模块提供修正值，不通过角色ID散落特判。三刀流、五档、黑足、狼草、阿修罗、鱼人空手道和援护反击必须使用同一管线。

### B-05 统一可选触发协议

要求：侠义、毛皮强化、宙斯二选一、谎言、净化和罗宾封存均使用可存档的选择窗口。人类始终能按文案选择或放弃；AI使用价值评分。选择窗口恢复后不得重复扣费、重复抽牌或重复推进梦想。

### B-06 军八AI知识隔离

要求：AI目标选择只能读取公开身份、公开行动、已查看的信息和行为推测，不得读取未公开`roleId`、隐藏手牌或真实伏笔。巨大树、海流护航、治疗、护盾和全体牌均应按相同可见信息规则处理。

### B-07 统一装备变化事件

要求：装备进入、离开、交换、替换和被移除均经过统一入口。事件必须能区分装备所有者和技能来源，避免把“别人让弗兰奇失去装备”错误识别为别人自己的装备变化。替换应作为一次原子操作，存档恢复后不重复触发。

### B-08 建立梦想航迹遥测

每局至少记录每名角色的航迹推进轮次、原因、觉醒轮次、觉醒后招牌技次数和未觉醒结束原因。批量报告必须同时输出胜率、四座位胜率、觉醒率和长局数据，避免只看总胜率。

## 8. 实施优先级

### P0：必须优先完成

1. 修复布鲁克未觉醒免死和灵魂乐章额外少摸牌。
2. 完整接入乌索普谎言流程。
3. 修复甚平侠义、海流护航和鱼人空手道。
4. 建立统一攻击穿甲与一次性强化管线。
5. 修复娜美航海术、顺风航线和卡牌事件时点。
6. 补齐索隆、山治、乔巴、罗宾的缺失技能。
7. 设置护盾上限3并随机化2V2首行动座位。
8. 禁止军八效果和AI读取隐藏真实阵营。

### P1：P0通过后完成

1. 改进乌索普、山治、罗宾、弗兰奇和甚平的角色AI评分。
2. 统一装备变化事件与所有伟大航路装备触发。
3. 在UI显示一次性突击强化、援护反击、诊断、侠义次数和封存归还对象。
4. 增加航迹原因、觉醒轮次和角色技能使用遥测。
5. 进行四座位各500局的第二轮平衡复测。

### P2：复测后才允许决定

1. 路飞或布鲁克仍高于60%时执行第二阶段削弱。
2. 罗宾或弗兰奇仍低于40%时执行文档中的条件性补强。
3. 娜美仍高于60%时降低气象棒触发频率。
4. 任何角色觉醒率不在25%至70%时调整梦想条件，不直接用基础数值补偿。
5. 若护盾封顶后仍有超过80轮的对局，再设计第40轮后的长局收束规则。

## 9. 测试与验收标准

### 9.1 公共梦想机制

- [ ] 每名角色每轮最多推进1点航迹，进度上限3。
- [ ] 达到3点立即觉醒，觉醒后不再推进。
- [ ] 被取消的牌、完全未产生实际变化的治疗和未增加数值的护盾不推进梦想。
- [ ] 每个航迹推进原因都有独立测试与日志。
- [ ] 四座位样本中每名角色觉醒率初步处于25%至70%。

### 9.2 十名角色关键正确性

- [ ] 路飞见闻色严格按牌堆顶类别结算，觉醒五档能正确穿甲。
- [ ] 索隆三刀流和阿修罗都能推进梦想，未觉醒阿修罗命中不摸牌。
- [ ] 娜美觉醒航海术只能获得不同类别的两张牌，置顶顺序保持选择顺序。
- [ ] 乌索普谎言会令目标弃另一张牌或取消当前牌，并正确回收或弃置暗置牌。
- [ ] 山治无武器时获得距离和穿甲，援护反击在使用后清除。
- [ ] 乔巴诊断双方各摸1，毛皮强化可放弃，净化只清除一个异常或一层。
- [ ] 罗宾不会对空目标支付能量，封存牌在目标下回合开始归还。
- [ ] 弗兰奇觉醒工坊替换下来的装备回到手牌。
- [ ] 布鲁克未觉醒时不能免死，同回合第二次突击伤害不重复施加黄泉寒气。
- [ ] 甚平侠义只保护其他角色，觉醒海流护航援助他人不弃牌。

### 9.3 模式、AI与长局

- [ ] 每名伟大航路角色至少完成四座位各500局纯包2V2。
- [ ] 修复正确性后没有角色归一化胜率高于60%或低于40%。
- [ ] 苍、绯队在至少10000局中胜率均处于48%至52%。
- [ ] 护盾始终不超过3点，至少99.9%的2V2在4000步内结束。
- [ ] 2V2轮数P99不超过30，超过80轮的对局为0。
- [ ] 未公开军八身份不参与AI和全体敌方效果筛选。
- [ ] 所有对局结束时没有遗留选择、弃牌、响应和多步策略窗口。

### 9.4 存档与UI

- [ ] 娜美多步牌序、乌索普谎言选择、罗宾封存选择、乔巴净化和甚平侠义窗口都可确定性恢复。
- [ ] 非乌索普本人只能看到谎言数量与目标，看不到暗置牌内容。
- [ ] 封存牌界面显示归还对象与归还时点，不泄露本不应公开的牌面。
- [ ] 头像显示`0/3`、`1/3`、`2/3`或“觉醒”，详情能查看梦想条件和觉醒收益。

其中`balance:test`执行固定种子的短样本和关键角色正确性探针；四座位各500局与10000局阵营报告作为发布前测试单独运行。

## 10. 建议修改范围

- `src/packs/one-piece.js`：十名角色主动技、被动技、招牌技、梦想触发和觉醒收益。
- `src/engine.js`：谎言前置事件、攻击修正管线、选择窗口、护盾入口、装备事件、卡牌生命周期和AI知识隔离。
- `src/data.js`：只在最终规则确定后同步技能文字；第一轮不先改文案掩盖代码缺失。
- `src/app.js`：梦想航迹、一次性状态、谎言可见性、封存信息和选择提示。
- `test/engine.test.js`：每名角色至少覆盖主动技、两项特性、招牌技、航迹条件和觉醒变化。
- `test/one-piece.test.js`：建议新建，集中覆盖伟大航路多步选择和跨回合状态。
- `test/balance-simulation.test.js`与`scripts/balance-report.mjs`：四座位、觉醒率、阵营与长局报告。

## 11. 调整原则

1. 先修错误，再改数值；乌索普、甚平、罗宾和弗兰奇不得用加体力掩盖核心技能未生效。
2. 角色文案是第一轮实现基准；若决定改变文案，必须作为明确的设计调整，而不是迁就现有代码。
3. 梦想航迹是扩展包公共特色，每名角色都应在正常对局中有可感知但不自动的觉醒机会。
4. 固定0号座位胜率不能单独用于平衡，必须同时查看四座位归一化和先手随机化后的结果。
5. 一轮只改变一个主要强度来源；路飞、娜美和布鲁克完成正确性修复后必须先复测再决定第二刀。
6. 所有隐藏信息、可选触发和多步选择必须支持确定性存档恢复。
7. AI模拟用于发现极端问题，最终数值微调至少加入真人2V2和军八记录。
