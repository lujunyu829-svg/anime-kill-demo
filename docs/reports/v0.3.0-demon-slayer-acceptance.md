# v0.3.0《日轮与血月》固定种子验收

日期：2026-10-08。范围仅为网页版十名鬼灭角色在现有 2V2、经典军八规则下的功能与平衡验证；不是 Windows/Android 安装包验收。

## 可复现方法

使用 `node scripts/balance-simulation.mjs`，`--seed=20261008`，`seedStep=7919`。2V2 每角色按四个 `anchor` 均分样本，报告记录版本、源码 SHA-256、角色池、种子范围、胜负、轮数、步数、未完成及残留窗口。主要命令：

```powershell
node scripts/balance-simulation.mjs --pool=demon-slayer --games=100 --seed=20261008 --output=docs/reports/v0.3.0-demon-slayer-final-pure.json
node scripts/balance-simulation.mjs --pool=mixed --characters=tanjiro,zenitsu,inosuke,shinobu,giyu,rengoku,mitsuri,nezuko,akaza,muzan --games=100 --seed=20261008 --output=docs/reports/v0.3.0-demon-slayer-final-mixed.json
node scripts/balance-simulation.mjs --pool=mixed --mode=classic8 --scenario=pressure --games=1000 --seed=20261008 --output=docs/reports/v0.3.0-demon-slayer-final-army8.json
```

异常角色另外用 `--characters=<角色ID> --games=250` 跑每环境 1,000 局同种子对照，报告命名中 `before/current/range/hand/cost/hp/active` 标出每个连续迭代。混合池包括全部 36 人；纯包包括本包十人。

## 单变量决策

- 义勇的保护技能原本距离 1，2V2 交错座次中队友固定距离 2，属于机制性不可用；两项保护范围均修为 2。随后依次试手牌上限 4→5、凪费用 3→2、体力 4→5、静水护形费用 1→0。每次先新增失败测试再修改，并用相同种子复测。最终 1,000 局达到纯包 41.4%、混合 43.8%，保留这些迭代。护形仍每回合限一次。
- 胡蝶忍的蜈蚣之舞费用 3→4，随后手牌上限 5→4；分步对照后最终进入可接受区间。
- 善逸的六连费用 3→4；同种子对照由 66.3%／62.3% 降为 55.8%／51.4%（各环境 1,000 局）。
- 无惨的血液烙印费用 1→2；同种子对照由 65.9%／62.6% 降为 52.7%／49.8%。
- 猗窝座的灭式费用 4→3；同种子对照由 42.8%／37.4% 升为 52.0%／47.0%。
- 伊之助纯包边界复核为 60.2%，仅超门槛 0.2 个百分点且混合池为 57.2%。试调猪突猛进费用 1→2 后降为 46.0%／44.6%，同时连带减少招牌技使用，调节过猛，已回退。将纯包轻微越界记为观察例外，不声称完全进入 40%～60%。
- 炼狱 400 局样本纯包 39.5%，扩大至 1,000 局为 40.5%，未修改。炭治郎初始偏弱但最终随环境变化回到观察区间，也未强行加数值。

## 稳定性与例外

- 最终纯包 4,000 局、混合 4,000 局、军八 1,000 局：未完成均为 0、残留窗口均为空、超过 80 轮为 0；最大步数分别为 469、530、689，远低于 2V2 的 4,000 步与军八的 8,000 步上限。
- 最终 2V2 轮数 P99 均为 43，军八 P99 为 42。这是既有长尾节奏的延续，未达到旧 v0.2.1 的 P99≤30 目标；本包原型验收规格将其列为非阻断观察项，不能据此宣称节奏目标达成。
- 军八原始角色胜率没有按身份与座次校正，只用于兼容和终局检查，不用于数值判断。
- 最终顺序执行 `npm test`（396/396）、`npm run build`、`npm run app:test`（396/396）、`npm run app:build`，全部成功。旧版 schema 2 存档路由及新角色多步选择恢复在上述测试中覆盖。
- 在本地 v0.3.0 页面实际点击验证：鬼灭筛选显示 10 人、炭治郎技能预览可见、排位 2V2 进入后显示 4 个席位、经典军八进入后显示 8 个席位。此检查使用隔离的无头 Edge；未进行真实 Android/Windows 设备验收。
